# Saved experiment configurations

These six JSON files are copied from the saved environmental sweep, fixed-proxy-rate comparison, temporal and spatial trajectories, and two topology experiments. They record the actual parameter settings and seeds used for those runs.

They are provenance records rather than a universal input format. Match the corresponding command-line options when rerunning. The four-configuration ablation command is documented in the repository README; the parameter-map settings are explicit constants in the three generator scripts.
